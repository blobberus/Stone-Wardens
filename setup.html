Set the site password

Owner-only setup. This page encrypts a GitHub token with the site password and stores the ciphertext as vault.json in the repo. The password itself is never saved anywhere. Anyone who knows the password can read and save campaign data. Everything here runs in your browser.

1. Create a fine-grained token

  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Stone-Wardens.
  3. Permissions → Repository → Contents: Read and write. (Metadata: read is added automatically.) Nothing else.
  4. Pick an expiration. When it expires, come back here and run setup again with a new token.

2. Encrypt it with the site password

After committing, GitHub Pages redeploys in about a minute. Then open the site and enter the password.
