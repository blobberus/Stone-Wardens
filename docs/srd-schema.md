# srd/ data schema (D&D 2024 / SRD 5.2)

Generated by `python -I tools/build_srd.py <5e-database src/2024/en>`. Never edit `srd/*.json` by hand; `srd/stubs/*.json` are hand-written.
Load files with `srd('classes')` or `srd('stubs/feats')` from `core/compendium.js`. Every list is an array of objects with a unique, stable slug `id`; `features.json` is an object keyed by id.
**Conventions:** every `description` is Markdown (render it with `renderMarkdown`). Ability ids are `str dex con int wis cha`. Skill ids are `acrobatics … survival` (see `rules.skills`). Tool, gear, weapon and armor ids are equipment ids (`thieves-tools`, `cartographer-tools`, `lute`). Category ids are `artisans-tools musical-instruments gaming-sets other-tools holy-symbols arcane-foci druidic-foci equipment-packs ammunition adventuring-gear`. `cost` is `{qty, unit}` with unit `cp|sp|ep|gp|pp`, and weight is in lb. Stubs add `source` ("PHB 2024", "XGE", "TCE", "MPMM"…), `stub:true`, optional `legacy:true` (2014-era) and `verify:true` (not checked against the book). Stub ids never collide with SRD ids.

## classes.json — `[Class]` (12)
`{id, name, hitDie, primaryAbility:[abil], primaryAbilityMode:'and'|'or'|null, saves:[abil], proficiencies:{armor:['light'|'medium'|'heavy'|'shields'], weapons:['simple'|'martial'|weaponId], tools:[toolId], weaponsNote?}, skillChoices:{choose, from:[skillId]}, toolChoices?:{choose, from:[toolId], text}, startingEquipment:{text, options:[EquipOpt]}, multiclass:{prereq:{all|any:[{ability,min}]}, proficiencies:{armor, weapons, tools, skills?:{choose,from}, toolChoices?}}, spellcasting:Casting|null, subclassLevel:3, subclassFeatureLevels:[3,6,…], subclasses:[id], levels:[Level×20]}`
- `EquipOpt = {label:'A', items:[{id, qty, name, note?} | {category: catId|[catId], qty, name, sameAsTool?}], gp}`. `sameAsTool` means "the same kind you picked for your tool proficiency".
- `Casting = {ability, kind:'full'|'half'|'pact', prepared:true, list:classId, focus, changePrepared:'long-rest'|'long-rest-one'|'level-up', ritual:'prepared'|'spellbook', spellbook?:{start:6, perLevel:2}, notes?}`. `long-rest-one` means swap one spell after a Long Rest. Fighters and Rogues get `kind:'third'` only through the stub subclasses (Eldritch Knight / Arcane Trickster).
- `Level = {level, prof, features:[featureId], counters:{…}, slots?:[s1..s9], pact?:{slots, slotLevel}, cantrips?, preparedSpells?}`. The caster fields appear only for casters; `preparedSpells` counts level 1+ spells only.
- `counters` (per class): barbarian `rage_count rage_damage_bonus weapon_mastery`; bard `bardic_inspiration_die:'d6'`; cleric/paladin `channel_divinity_charges`; druid `wild_shape_uses wild_shape_known_forms wild_shape_max_cr:'1/4' wild_shape_fly`; fighter `second_wind_uses weapon_mastery`; monk `martial_arts_die:'d6' focus_points unarmored_movement_bonus`; paladin `lay_on_hands_pool weapon_mastery`; ranger `favored_enemies weapon_mastery`; rogue `sneak_attack:'3d6' weapon_mastery`; sorcerer `sorcery_points`; warlock `eldritch_invocations`.
- From the 2nd appearance onward, the subclass placeholder in `features` becomes `<class>-subclass-feature`: grant the subclass features whose `level` equals that class level.

## features.json — `{featureId: Feature}` (class + SRD subclass features)
`{id, name, class, subclass:subclassId|null, level, levels?:[…every class level it is listed at], description, choice?:Choice, alwaysPrepared?:{"<classLevel>":[spellId]}, spellLists?:[classId], grants?:{saves?, languages?}}`
- **A feature id listed at several levels grants its `choice` again each time** (ASI 4/8/12/16, Expertise 1+6, Metamagic 2/10/17, Mystic Arcanum 11/13/15/17).
- `alwaysPrepared` spells are gained once the class level reaches the key. They don't count against `preparedSpells`.

## Choice objects (shared by features, subclass features, species traits, feats, stubs)
Common optional keys: `key` (stable slug to store the pick under), `count`, `countKey` (a **total** read from `levels[L-1].counters[countKey]`; top the picks up whenever it rises), `countByLevel:{"3":3,"7":5}` (total by class level), `changeable:'long-rest'|'short-rest'|'level-up'|'recast'`, `perUse:true` (decided at use time; don't store it), `note`.

| type | extra keys | builder renders |
|---|---|---|
| `subclass` | — | pick a subclass of this class (SRD + stubs) |
| `asi-or-feat` | — | the `ability-score-improvement` feat, or any feat whose `prereq` the character meets |
| `feat` | `category:'origin'\|'general'\|'fighting-style'\|'epic-boon'`, `orAnyFeat?`, `alternatives?:[{id,name,description}]` | feat picker filtered by category (`alternatives` = Blessed/Druidic Warrior) |
| `ability-increase` | `points`, `from:[abil]`, `max` (20, or 30 for boons), `maxPerAbility?` | spend the points (ASI feat: 2 points, max 2 per ability) |
| `weapon-mastery` | `countKey` or `count` | pick weapon ids (simple or martial) whose mastery you can use |
| `expertise` | `count`, `from?:[skillId]` | pick skills you're proficient in; they get double proficiency |
| `skills` | `count`, `from:[skillId]\|'any'` | skill proficiency |
| `tools` | `count`, `from:[toolId]\|catId` | tool proficiency |
| `skills-or-tools` | `count` | any mix (Skilled) |
| `languages` | `count` | from `rules.languages` |
| `options` | `options:[{id,name,description?,prereq?,repeatable?,grants?,alwaysPrepared?,resistance?,choice?}]` | menu. `prereq` = `{level?, invocation?, text}`; an option's own `choice` opens after it's picked |
| `spells` | `count`, `list:[classId]\|'any'\|'spellbook'`, `listFrom?`, `level: n\|[min,max]\|'slot'\|'cantrip-or-slot'`, `levelByClassLevel?`, `school?`, `ritual?`, `alwaysPrepared?`, `addToSpellbook?`, `known?` | spell picker. `'slot'` = any level you have slots for; `listFrom` names another part's `key` (e.g. Magic Initiate's `spell-list`) |
| `spellcasting` | `class` | standard caster UI driven by `levels[].cantrips/preparedSpells/slots` |
| `wild-shape-forms` | `countKey:'wild_shape_known_forms'` | free-text beast list (max CR in counters) |
| `ability` | `key`, `from:[abil]` | pick one ability (e.g. `spellcasting-ability`) |
| `damage-type` | `from:[damageTypeId]` | pick one damage type |
| `subspecies` / `size` | `from:['Small','Medium']` for size | pick from `species.subspecies` / `sizeOptions` |
| `multi` | `parts:[Choice]` | render every part |

Extra keys seen in stubs: `feat.from:[featId]` (a fixed shortlist), `countFrom:'proficiency-bonus'` (count = PB), `minLevel` (character level), and a `note` on skills such as "or one language instead". `grants` (on features, options, traits and feats) are optional hints for automation: `{weapons ('martial','improvised',id), armor, saves, skills ('all' allowed), tools, languages, resistances, cantrips:n, spells:[{id, level?}], feat:'origin'}`. Spell ids that aren't in `spells.json` (non-SRD spells) are fine: show them by name and leave them unresolved.

## subclasses.json + stubs/subclasses.json — `[Subclass]`
`{id, name, class, summary, description, features:[{id, name, level, description, choice?, alwaysPrepared?, expandedSpells?, verify?}], source?, stub?, legacy?, spellcasting?:{ability, kind:'third', list, note, levels:[{level, cantrips, prepared, slots:[s1..s4]}], verify?}}`. `expandedSpells` (`{"<classLevel>":[spellId]}`, 2014 warlock patrons) adds spells to the class list without preparing them. SRD subclass features are also in `features.json`. Under 2024 rules a character picks a subclass at level 3. Legacy (2014) subclasses keep their 2014 feature levels; the builder grants any feature below level 3 at level 3.

## species.json + stubs/species.json — `[Species]`
`{id, name, type, size|sizeOptions:[…], speed, speeds?:{fly,swim,climb}, darkvision:ft|null, traits:[Trait], subspeciesLabel?, subspecies?:[{id, name, traits:[Trait], damageType?, darkvision?, speed?}], notes?}`. `Trait = {id, name, description, level? (character level it unlocks, default 1), spell?, speed?, choice?, grants?, unarmed?:{damage,type}, unarmoredAC?:{base,dex}, acBonus?}`. A subspecies' `darkvision`/`speed` overrides the species value. Ability scores always come from the background, never the species. Example subspecies: `{"id":"elven-lineage-drow","name":"Drow","darkvision":120,"traits":[{"id":"lineage-spell-faerie-fire","level":3,"spell":"faerie-fire",…}]}`.

## backgrounds.json + stubs — `[Background]`
`{id, name, abilityScores:[a,b,c], feat:{id, note}, skills:[2], tool:{id,name}|{category, name, from:[toolId]}, equipment:{text, options:[EquipOpt]}, description?}`. `feat.note` names the Magic Initiate list (Cleric / Wizard / Druid). Apply +2/+1 or +1/+1/+1 to the three listed abilities (max 20; see `rules.backgroundAbilityIncrease`).

## feats.json + stubs — `[Feat]`
`{id, name, category:'origin'|'general'|'fighting-style'|'epic-boon', prerequisite:text|null, prereq:{level?, abilities?:{any|all:[{ability,min}]}, feature?:'Fighting Style', spellcasting?:true, proficiency?:'medium-armor'}|{}|null, repeatable, repeatableNote?, description, choice?, grants?}`. Almost every general feat and epic boon has an `ability-increase` choice, sometimes inside a `multi`. Example: `{"id":"grappler","category":"general","prereq":{"level":4,"abilities":{"any":[{"ability":"str","min":13},{"ability":"dex","min":13}]}},"choice":{"type":"ability-increase","points":1,"from":["str","dex"],"max":20}}`.

## spells.json — `[Spell]` (339)
`{id, name, level (0 = cantrip), school, classes:[classId], castingTime:'Action'|'Bonus Action'|'Reaction'|'1 minute'…, castingTrigger?, ritual, range, components:['V','S','M'], material|null, duration, concentration, description, higherLevel|null, attack?:'melee'|'ranged', save?:abil, damage?:{type, dice}, statBlock?}`. For cantrips, `higherLevel` is the Cantrip Upgrade text. When `concentration` is true, show the duration as "Concentration, up to 1 minute". `statBlock` is Markdown for the summoned creature.

## weapons.json (38) / armor.json (13) / gear.json / magic-items.json
- Weapon `{id, name, category:'simple'|'martial', kind:'melee'|'ranged', damage:'1d8', damageType, versatile:'1d10'|null, properties:[propId], mastery:masteryId, range:{normal,long}|null, thrown:{normal,long}|null, ammunition?:gearId, notes?, weight, cost}`. Example: `{"id":"longsword","damage":"1d8","damageType":"slashing","versatile":"1d10","properties":["versatile"],"mastery":"sap"}`.
- Armor `{id, name, category:'light'|'medium'|'heavy'|'shield', ac:{base, dex:bool, maxDex:2|null}, strMin|null, stealthDisadvantage, weight, cost, don, doff}`. For a shield, `ac.base` (2) is a bonus.
- Gear `{id, name, category:catId, cost, weight, description, tool?:true, ability?, utilize?:[{name,dc}], craft?:[id], contents?:[{id,qty}] (packs), quantity?, storage?}`.
- Magic item `{id, name, category:'wondrous-item'|'armor'|'weapon'|'ring'|'potion'|'wand'|'staff'|'rod'|'scroll', type, rarity:'common'|'uncommon'|'rare'|'very-rare'|'legendary'|'artifact'|'varies', rarityText?, attunement:bool, attunementNote?, variantOf?, variants?, description}`.

## rules.json
`abilities[{id,name,full,description}] skills[{id,name,ability,description}] alignments languages[{id,name,rare,note?}] startingLanguages conditions damageTypes weaponProperties weaponMasteries magicSchools sizes` (each a list of `{id,name,description}`), plus `profBonusByLevel[20] xpByLevel[20] standardArray pointBuy:{budget:27,min:8,max:15,cost:{"8":0…"15":9}} abilityScoreMax backgroundAbilityIncrease hitPoints multiclassSlotTable[20][9] multiclassCasterLevel currency[{id,name,gp}] carryingCapacity`.

## Character-engine rules
- Ability modifier = `floor((score-10)/2)`. Proficiency bonus = `rules.profBonusByLevel[totalLevel-1]`. Expertise doubles it. Bard Jack of All Trades adds half (rounded down) to non-proficient ability checks.
- HP: level 1 = max hit die + CON modifier. Each later level adds `hitPoints.perLevelFixed[hitDie]` (or a roll) + CON modifier. Multiclassing uses the first class's hit die at level 1.
- AC: no armor = 10 + DEX (Barbarian Unarmored Defense: + CON; Monk: + WIS, no shield). Armor = `ac.base` + DEX (capped at `maxDex`) if `dex`; shield +2. Heavy armor below `strMin` costs −10 ft of speed.
- Spell save DC = 8 + prof + casting ability modifier; spell attack = prof + casting ability modifier.
- Weapon attack = ability modifier + prof (if proficient). Use STR for melee and DEX for ranged; finesse weapons use the higher of the two. The weapon's mastery is usable if its id is among the `weapon-mastery` picks.
- Prepared spells and cantrips: each class uses its own `levels[classLevel-1].preparedSpells/cantrips` and its own list. Always-prepared and feat or species spells are extra.
- Slots for a single class: `levels[L-1].slots`. **Multiclass**: caster level = full-caster levels + `ceil(half-caster levels / 2)` + `floor(third-caster levels / 3)`; slots = `rules.multiclassSlotTable[casterLevel-1]` (if only one class casts, use that class's own table). Warlock `pact` slots are kept separate and recharge on a Short Rest.
- Multiclassing needs the `multiclass.prereq` scores of the new class **and** of the current class(es). A new class grants only `multiclass.proficiencies`.
- Feats: Origin feats at level 1 (background feat; Humans get an extra one via Versatile). `asi-or-feat` happens at class ASI levels. Epic Boon at level 19.
